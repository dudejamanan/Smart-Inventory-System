# Profiles supported by the same rules

| Profile | Badge / item examples | Suggested policy |
|---|---|---|
| College component store | student badge; resistor kit, multimeter, Raspberry Pi tags | strict_issue; levels 1–3; short demonstration loan |
| Library cabinet | borrower badge; separately tagged book/device | strict_issue; longer loan_minutes; shelf slots for individually observed objects |
| Tool crib | technician badge; tagged tool | strict_issue; level/zone permission; record return by another worker |
| Pharmacy training cabinet | staff badge; tagged demonstration package | supervised prototype only; no claims of medical inventory compliance or authenticity |

Every physically observed item needs its own linked slot/marker. This camera pipeline does not count arbitrary loose objects, identify unlabelled objects, or certify package contents. RFID UIDs are clonable identifiers. Real deployment requires additional controls beyond this lab prototype.
